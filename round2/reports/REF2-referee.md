# REF2. Hostile referee, round two (k = 4)

Scope: character sums over finite fields, where the bound is Weil's theorem (1948). Nothing here concerns the Riemann Hypothesis for the integers. No proof below uses weights, purity, the Weil bound or the Weil conjectures. Weights are used only to read data, and each such use is marked "(weights, interpretation)".

Labels: PROVED, CITED, CHECKED (exact integer arithmetic; script and file named), OPEN, HINT.

Files (all under `round2/compute/REF2/`): `lib.py` (own N_4 routines), `x4_test.py`, `x4_test_out.txt` (large p), `x4_test_smallp_out.txt`, `x1_mult.py`, `x1_mult_out.txt`, `x1_mult_smallp_out.txt`, `line_exc.py`, `line_exc_out.txt`.

## 0. Verdict for k = 4

**PROVED_FOR_GENERIC_C.** Exact statement (this is K4T Theorem D, re-derived by me, with two repairs listed in section 2):

Let q be odd, f in F_q[x] squarefree of odd degree d >= 3 with f(0) != 0, Z its roots in F-bar, mu = {rho : rho Z = Z}, R' = {z'/z : z, z' in Z}, S = {0} union R'. Assume f is NOT of the form x^d - a. Let c = (c_1,c_2,c_3) in (F-bar^*)^3 satisfy

 (X4) c_2 + c_3 s + c_1 s' != 0 for every pair (s, s') in S x S.

(This contains X0: c_1+c_2+c_3 != 0, and X1: c_2 + c_3 rho + c_1 rho' != 0 for rho, rho' in mu.) Then H^j_c(Y_c,K) = 0 for every j != 3, i.e. (S_4) holds. If mu = {1}, dim H^3_c = 4d^3 - 3d^2 + 4d - 1 (92 for d = 3).

Exceptional set of the theorem: the f = x^d - a family (OPEN, not decided), and at most (d^2-d+2)^2 - 1 lines in the (c_1:c_2:c_3) plane (63 for d = 3), together with c_i = 0 (outside the family). Inside it, X0 and X1 are genuine failures (PROVED, and confirmed quantitatively in section 4); X4 minus X1 is not a failure on any data I could reach (section 4).

What the theorem does not do: it gives q^(7/8) at k = 4 and says nothing for k >= 5, so it does not make the route a proof of the Weil bound. The route needs the input for infinitely many k.

Standing caveat: every foundation theorem used is classical (Kunneth, proper base change, Leray, Poincare duality on a curve, Grothendieck-Ogg-Shafarevich, SGA 1 XIII for tame pi_1, Artin vanishing for the lower half). I re-derived each application. I did not open the primary sources for the theorem numbers; LIT opened several and found no weights in them. I did not find a step that uses weights.

## 1. Re-derivation of K4T, step by step (nothing found wrong in the main chain)

1. **Fibration.** PROVED by my own derivation, independent of report I. Put u = c_2 x_2 + c_3 x_4. Then Q = det [[c_1 x_1, x_3],[-u, x_2]]. Rank <= 1 gives x_3 = r c_1 x_1, x_2 = -r u, x_4 = u(1 + c_2 r)/c_3. So the plane over r has coordinates (x_1, u) and the weight is t(x_1)t(c_1 r x_1) * t(-r u) t(u(1+c_2 r)/c_3), a product of two rank-one pieces. The two ratio parameters are s = c_1 r and s'' = -(c_1 + c_2 s)/(c_3 s). Using C(1/s) = C(s) (canonical isomorphism V(1/s) = V(s), substitution x -> s x) and sigma = 1/s, they become sigma and -(c_1 sigma + c_2)/c_3, K4T's linear tau up to the reversal c_1 <-> c_3. The planes with both ratios in mu lie in Y exactly when c_2 + c_1 rho + c_3 rho' = 0, equal to K4T's condition because S x S and mu x mu are symmetric.
2. **Leray, degrees.** Re-derived. R^1 constant, R^2 = V tensor tau^*V, R^3, R^4 skyscrapers; E^{2,3} = E^{3,2} = E^{1,3} = E^{1,4} = 0. So H^5_c = H^6_c = 0 and H^4_c has exactly the pieces E^{0,4} (no differentials in or out) and coker(d_2 : E^{0,3} -> E^{2,2}). No error.
3. **E^{2,2} = (V tensor tau^*V)_pi (-1).** Re-derived (H^2 of a constructible sheaf on P^1 equals H^2_c of its lisse locus; Poincare duality). No error.
4. **V tame everywhere (K4T section 3).** Re-derived both Euler characteristics. From the product structure: chi_c(T) = d^2 - d + 1 (U' = G_m x A^1 gives d(d-1), the line x = 0 gives 1, H^3_c(T) = 0). From p: stalk dimensions 2d-1 generic, d-1 at r = 0, 2d-1-c_r on R' with the correction h^2 at mu, total deficit d + d^2 - |mu|, so chi_c(T) = d^2 - d + 1 + Sw_total. Hence Sw_total = 0, so V is tame at every point including infinity. The argument is sound. It uses only GOS and Swan >= 0.
5. **Lemma S-c.** Re-derived: kernel contains N = sum of (g-1)A over finite inertia, A/N is a representation of pi_1(A^1) trivial on wild inertia at infinity, so it factors through pi_1^t(A^1) = 1 (Riemann-Hurwitz). Disjointness is needed at finite points only. Correct as K4T states it. The ell-adic (non-finite image) case is covered because the kernel is a closed normal subgroup containing finite inertia and wild inertia at infinity.
6. **V_pi = 0 for mu = {1} (K4T 5.1, 5.2).** Re-derived. H^3_c(T) = 0 forces d_2 : E^{0,2} -> E^{2,1} = V_pi(-1) to be surjective, so V_pi(-1) = coker(H^2_c(T) -> prod over mu of H^2_c(T_rho)). For mu = {1} the image of H^2_c(U') = H^1_c(G_m,F) tensor H^1_c(A^1,F) already surjects onto H^2_c(T_1) = Q(-1): the restriction to the diagonal is a tensor b -> <a, iota^* b>, the Poincare pairing (F = j_*L = j_!L is self dual, perfect on G_m), and iota^* is injective with hyperplane image (purity of a point: H^1_{0}(A^1,F) = 0, H^2_{0} = F_0(-1), dims d-1 inside d). The extra class from the line x = 0 is irrelevant for surjectivity. The mixed product (a compactly supported in one factor only) is covered by naturality of cup product under forgetting supports. No error. Consistency: V_pi = W_pi since L_pi = 0, and W is irreducible of Lefschetz type (HINT), so no trivial quotient is expected.
7. **Euler characteristic of (Y,K), second route.** I recomputed chi_c(Y,K) by a different fibration: project to (x_2, x_3). On B = {x_2, x_3 != 0, f(x_2)f(x_3) != 0}, chi_c(B) = d^2; the fibre is the affine line {c_1 x_2 x_1 + c_3 x_3 x_4 = -c_2 x_2 x_3} with sheaf chi(f(x_1) f(alpha x_1 + beta)), alpha = -c_1 x_2/(c_3 x_3), beta = -c_2 x_2/c_3, chi_c = 1 - 2d + n(alpha,beta), n = #{(z,z') : alpha z + beta = z'}. The locus alpha z + beta = z' has chi_c = -2d-1 for generic c (removed points: x_3 = 0, d roots, the pole, d points with x_2 a root). So chi_c(over B) = (1-2d)d^2 - d^2(2d+1) = -4d^3. Boundary strata x_2 = 0, x_3 = 0, x_2 = x_3 = 0 give 2(d^2-d) + (d-1)^2. Total -4d^3 + 3d^2 - 4d + 1, equal to K4T (-92 at d = 3, -444 at d = 5). Label: CHECKED by hand (algebra, no script). It is a cross-check of K4T section 1, not a proof: additivity over this fibration is not proved (it would need a Swan statement). K4T's own count rests on the proved Swan = 0.
8. **Theorem B (planes).** Re-derived. Planes {x_4 = rho x_2, x_1 = rho' x_3} lie in Y iff c_2 + c_3 rho + c_1 rho' = 0 and K is geometrically trivial on them iff rho, rho' in mu. Each contributes a class Q(-2) to E^{0,4} that survives (no differentials). PROVED.

## 2. Defects found in K4T (all repairable, none in the main chain)

D1. **Wrong weight remark in section 8.** K4T says a nonzero E^{2,2} class "would have eigenvalue of size about q, far below the noise". (weights, interpretation) If Hom_pi(V, tau^*V^vee) != 0 with W irreducible, the pairing W tensor tau^*W -> Q(-1) gives E_pi = Q(-1) and so E^{2,2} = Q(-2), eigenvalue of size q^2, the same size as the X0 plane class. So the data test on the X4 lines is much stronger than K4T claims: a class there would be as visible as X0. Only a class from a weight-0 quotient (the f = x^d - a case, V_pi) would be of size q and invisible. This strengthens section 4.

D2. **Theorem C(ii) cites Deligne-Lusztig for the character count, and does not need to.** For mu of order m with 1 < m < d, f = g(x^m), e = d/m odd. The mu-isotypic piece H_chi = H^1_c(A^1_w, L_chi(g(w)) tensor L_Kummer(w)). By Euler characteristic on the w-line its dimension is e - 1 for chi = 1 and e for chi != 1 (g has e simple roots, g(0) = f(0) != 0, tame). For e >= 3 every character occurs, so the operators sigma_rho (rho in mu) are independent in End(H), and V_pi = 0. For e = 1 (f = x^d - a) the trivial character is missing and dim V_pi <= 1, as K4T says. PROVED by this elementary count; the DL reference is not needed. The normalisation of the equivariant structure is exact here because f(rho x) = f(x) (order of rho divides d), not only up to a constant.

D3. **"Not tested" note.** K4T section 8 list F does not include the X4 lines with s = 0 or s' = 0. My test (section 4) includes S = {0} union R'.

D4. **Definition of S is sufficient, not sharp.** V is lisse off S; a smaller true ramification set may make the theorem hold on more lines. Not an error.

No use of weights, no unproved irreducibility or semisimplicity, no tameness assumption left unproved, no misuse of the fundamental group fact, and no mishandled special point was found. Special points checked: r = 0 (stalk d-1, ramified, in S), r = -e (tau^{-1}(0)), r = infinity (tame; both sheaves tame there, harmless), r = 1 and mu (stalk d, unipotent), ratio points (one transvection each). The case where singular sets meet is exactly X4, treated as an exception (conditional part below).

## 3. The conditional part, checked

K4T's Conditional Theorem: for mu = {1}, assume (Irr) W irreducible and (Loc0) T_0 on W has eigenvalue -1. Then H^4_c = 0 for every c with c_1+c_2+c_3 != 0. My check of the logic: a nonzero phi : V -> tau^*V^vee has image a quotient of V and a sub of tau^*V^vee. If V is a nonsplit extension of irreducible W by L, a rank-one quotient is impossible; L_chi(r) cannot be a sub of tau^*V^vee because e != 0 separates the ramification points. So a common factor must be W isomorphic to tau^*W^vee, impossible at r = 0: T_0 on W has eigenvalue -1 and tau^*W^vee at 0 is unipotent or trivial. The logic is correct given (Irr) and (Loc0). (Irr) and (Loc0) are OPEN as K4T says. The two-scale picture behind (Loc0) (cluster at z/r with twist chi(r^{-d}) = chi(r), d odd) is plausible (HINT). So the lines X4 minus X1 are not shown to be failures, and by section 4 they are not failures on the data.

## 4. The exceptional list against the data (CHECKED, exact integers)

Then I computed the entire table of N_4 over all (c_2, c_3) in (F_p^*)^2 with FFT (cross-correlation of C with itself), and verified the FFT route against the direct integer sum on 300 random c per case (0 differences, field "fftverify_bad=0"). All counts below are exact integers; N/p^2 are decimals for reading. The scale p^2 is the size of the plane class.

## 5. Agreement of RED, FS and K4T on k = 4

- Degrees. RED (claim 4: nonzero only for j in {k-1,k,k+1}) and round one (H^5_c = H^6_c = 0) agree with K4T Theorem A: H^5_c = H^6_c = 0.
- X0. RED (plane {x_1 = x_3, x_2 = x_4}, constant quotient Q(-2), eigenvalue q^2, N_4 = (p-r)^2 + O(p^{3/2}) on 146 rows) agrees with K4T Theorem B (rho = rho' = 1). I strengthen both: X1 for mu != {1}, with m planes giving N/p^2 near m (section 4b).
- Sign. RED's note that H^{k+1}_c carries the same trace sign as H^{k-1}, so only H^k_c matters, is consistent with K4T (at k = 4 H^5_c = 0 anyway).
- Lower half. RED re-derived it: K[k-1] is perverse, since the support condition holds for a single sheaf in degree -(k-1) on a (k-1)-dimensional variety and the cosupport condition follows from the triangle j_!j^*P -> P -> i_*i^*P with j affine (i^*P in pD^{[-1,0]}). FS says the main session's one-line argument "is not by itself valid" and uses lci. I decide for RED: the one-line argument is valid when combined with the direct support count. (The generic claim "i^*P[-1] is perverse for any perverse P" is false; only i^*P[-1] in pD^{[0,1]} holds. But here the upper bound comes from the single-degree structure of K.) Both routes reach the same conclusion. No contradiction in the result.
- FS vs K4T on whether (S_4) is reproduced. FS could not reproduce the failure at X0 from boundary strata and could not decide surjectivity of H^3(Y,K) -> B^3; K4T decides H^4_c by another fibration. Not a contradiction: FS's group is the same H^4_c seen from a different compactification. FS's demand that the D_13, D_24 classes in B^4 be cancelled by lower strata is the right shadow of H^5_c = 0, and K4T proves H^5_c = 0 directly.
- Open items that K4T makes obsolete or leaves: RED's "R^{k+1} punctual" and "d_2" problems concern the fibration over h; K4T does not use that fibration for k = 4. RED's OPEN (surjectivity of H^4_c(Y,K) -> H^4_c(P,K), equivalently H^5_c(Y-P,K) = 0) is settled by K4T Theorem A for k = 4: H^4_c(Y,K) = E^{0,4} + E^{2,2}, and E^{0,4} is exactly the plane sum. At X0 with mu = {1}, RED's surjectivity onto H^4_c(P,K) = Q(-2) is PROVED regardless of E^{2,2}, because H^4_c(Y minus 0,K) -> E^{0,4} is onto (no differentials) and E^{0,4} is the restriction to the planes. Whether E^{2,2} also vanishes at X0 is the (Irr),(Loc0) question.
- Where I cannot decide: whether (Irr) and (Loc0) hold, so whether the lines X4 minus X1 are free of failures as a theorem.

The family traces behave as if H^3_c has few irreducible monodromy constituents, consistent with big monodromy. Not used anywhere.
