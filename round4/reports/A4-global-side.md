## 3. S8, S9, S10 from first principles

3.1 Elementary fibre bound (PROVED, own proof; in Lean this is Identity/Parseval). For h != 0, all c_i != 0, any F_{Q^n}: |S_h| <= Q^{n(k-1)/2} sum |t|^2 <= Q^{n(k+1)/2}.
Proof. Let B_i be the Q^n x Q^n matrix (psi_n(h c_i x y))_{x,y}; B_i B_i^* = Q^n Id because h c_i != 0, so the operator norm of B_i is Q^{n/2}. Let D = diag(t), norm <= 1 since |t| <= 1.
Then S_h = <t, B_1 D B_2 D ... D B_{k-1} t>, with t read as a vector, so |S_h| <= ||t|| Q^{n(k-1)/2} ||t||, ||t||^2 = sum |t|^2 <= Q^n. QED. Needs only |t| <= 1, h c_i != 0; psi_n any nontrivial additive character (this is what makes it valid after applying iota).
Consequences: |S_h| <= Q^{n(k+1)/2} and |R_n| <= (Q^n - 1) Q^{n(k+1)/2} < Q^{n(k+3)/2}.

3.2 Power-sum lemma (PROVED; Lean PowerSum.lean, Endgame2.lean). If sum_lambda a_lambda lambda^n = O(rho^n) as n -> infinity, finitely many distinct complex lambda, all a_lambda != 0, then |lambda| <= rho for all lambda.
Proof sketch: if r = max |lambda| > rho, the terms with |lambda| = r give g(n) = sum a_u u^n with unit-modulus distinct u (after dividing by r^n), and the mean of |g(n)|^2 over n is sum |a_u|^2 > 0 (distinct u), so g does not tend to 0; the rest is o(1) times ... contradiction with O((rho/r)^n) -> 0.

3.3 S8 (PROVED given (S5-out), 3.1, 3.2). Claim: every eigenvalue beta of Frob_Q on C has |iota(beta)| <= Q^{(k+1)/2}.
Take a closed point h_0 of U of degree m (U nonempty open of G_m over F_Q), a geometric point over it. The stalk V_{h_0} = H^k_c(A^k_{F-bar}, F_{h_0}) (proper base change) with Frobenius element Frob_{h_0} of pi_1(U) acting. The quotient map V -> C is pi_1(U)-equivariant and pi_1(U) acts on C through the Galois quotient, Frob_{h_0} mapping to Frob_Q^m. So eigenvalues of Frob_Q^m on C, namely beta^m, are among those of Frob_{h_0} on V_{h_0}.
By (S5-out) H^b_c(A^k, F_{h_0}) = 0 for b != k, so for every n the trace formula over F_{Q^{mn}} gives S_{h_0}(F_{Q^{mn}}) = (-1)^k sum_j gamma_j^n (gamma_j the eigenvalues of Frob_{h_0} on V_{h_0}, with multiplicity). Apply iota: iota(S) is the character sum with the nontrivial complex character iota o psi, so 3.1 applies (h_0 != 0, c_i != 0 in F_{Q^{mn}}): |iota(S)| <= Q^{mn(k+1)/2}. By 3.2 every |iota(gamma_j)| <= Q^{m(k+1)/2}. Hence |iota(beta)|^m <= Q^{m(k+1)/2}. QED.
Remark: here the signs of the gamma's are all equal because only one degree is nonzero: this is exactly where fibre vanishing is used, and where it replaces "weights": without it the fibre sum is an alternating sum and cancellation could hide large eigenvalues (the lemma 3.2 only bounds net coefficients).
